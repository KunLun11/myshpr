# Changelog

Формат — по мотивам Keep a Changelog. Версии — этапы плана из `TASKS.md`.

## [1.0.0] — релиз MVP (этап 7)

### Добавлено

- Playwright и пять E2E-сценариев: регистрация и мастер темы, проверка темы
  учителем, продукт, файл/чек-лист/комментарий, дашборд «кто застрял».
- Ночной workflow E2E против полного compose-стека и вложения трейсов.
- Rate limit в Redis для входа, регистрации, проверки темы и загрузки файлов;
  общий счётчик для нескольких uvicorn-воркеров. При недоступности Redis
  лимитер переходит в память процесса и не блокирует вход.
- JSON-логи с `request_id`, `user_id`, маршрутом, статусом и длительностью;
  `X-Request-ID` возвращается клиенту.
- Prometheus-метрики: запросы, гистограмма задержек, пул БД, фоновые задачи.
- Дополнительные security headers: Permissions-Policy, COOP, CSP, HSTS
  (включается настройкой).
- Prod-стек: Caddy с автоматическим TLS, приватные backend/db/redis,
  пароль Redis, volume для файлов, ротация логов, healthcheck frontend.
- Скрипты `deploy/scripts/backup.sh`, `restore.sh`, `smoke.sh`.
- `pip-audit` и `npm audit` в CI; prod-образ frontend собирается в CI.
- Документация: корневой `README.md`, инструкции ученика и учителя,
  чек-лист релиза, расширенный runbook.

### Изменено

- `python-jose` заменён на `PyJWT`: удалены уязвимые транзитивные зависимости
  `ecdsa` и `python-jose`.
- FastAPI в prod требует `RATE_LIMIT_BACKEND=redis`.
- `.github/` больше не игнорируется git — CI и workflow E2E коммитятся.

## [0.6.0] — этап 6

### Добавлено

- Админка без Payload (ADR-05): школы, учебные годы, справочники, шаблон
  чек-листа, контрольные точки, ученики и CSV-импорт, журнал аудита.
- `audit_log` с school-scope и JSONB-деталями; секреты не пишутся.
- Origin/CSRF guard для небезопасных методов.
- Страницы `/admin/**` с `noindex` и проверкой роли на сервере.
