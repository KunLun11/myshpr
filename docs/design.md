# Дизайн: направление и промпт для прототипа

Единый источник правды по визуальному языку приложения «Индивидуальный проект».
Промпт ниже копируется целиком в [open-design](https://open-design.ai/ru/) для
генерации прототипа. Реализация во `frontend/` должна следовать этому же брифу.

## Sky Glass — актуальная система (2026)

Визуальный язык переработан: вместо тёплой бумаги Mailchimp — «небо и стекло».
Светлая тема — воздушное небо с иридисцентными пятнами, ночная — глубокий
космос со звёздами и аврорами. Стеклянные поверхности, мягкое свечение и
дружелюбная типографика делают интерфейс ближе подросткам, не мешая чтению.

> Разделы ниже с палитрой Mailchimp и промптом open-design сохранены как
> исходная история брифа. При конфликте действует этот раздел и токены в
> `frontend/app/globals.css`.

| Градиент действий | `#4A4DF0 → #7A4DF0` | `#8EA6FF → #A58BFF → #6FD6FF` |
| Декоративные | Sky `#2FA8FF`, Mint `#16C79A`, Sunset `#FF7AB6` | те же, светлее |
| Ошибка | `#B4232A` + `#FFE2E5` | `#FF8A93` + `#33141A` |
| Успех | `#0B7A57` + `#D7F5EA` | `#5BE3B0` + `#0F2E26` |
| Предупреждение | `#8A5A00` + `#FFF0C9` | `#F5C56B` + `#2E2410` |

- Статус проекта по-прежнему дублируется иконкой, текстом и цветом.
- Контраст текста на светлых градиентах проверен: белый текст на Iris/Violet
  проходит WCAG AA; градиентный текст используется только для крупных заголовков.

### Типографика

- Заголовки и бренд — **Unbounded** (`font-display`), кириллица, tracking до `-0.045em`.
- Текст и интерфейс — **Nunito** (`font-sans`), body 15–17px, line-height 1.55.
- Кириллица обязательна для обоих шрифтов; `display: swap`.

### Материалы, эффекты и темы

- `.glass`, `.glass-strong`, `.glass-card`, `.glass-sky` — слои стекла с
  `backdrop-filter`, внутренним бликом и мягкой тенью.
- `.sky-backdrop` — фиксированные авроры в обеих темах и звёздное поле ночью.
- `.bg-primary-gradient`, `.bg-sky-gradient`, `.text-gradient` — фирменные градиенты.
- `.hover-lift`, `.stagger-list`, `.animate-fade-up`, `.animate-pop-in`,
  `.float-slow` — библиотека моушна.
- Переключатель тем — `components/theme-toggle.tsx`: `data-theme="light|dark"`
  на `<html>`, выбор сохраняется в `localStorage`, до первой отрисовки тема
  применяется inline-скриптом в `app/layout.tsx`.

### Моушн

- Микро 140–220ms, панели 240–360ms, easing iOS (spring/ease-out).
- Допустимо 1–2 медленных декоративных цикла на экран (дрейф неба, мерцание звёзд).
- `prefers-reduced-motion` и `prefers-reduced-transparency` полностью отключают
  эффекты и оставляют плотные поверхности.

## Контекст продукта

- Аудитория: ученики 9–11 классов и учителя-кураторы (плюс школьный админ).
- Задача: ученику — вовремя начать и не застрять на теме; учителю — увидеть,
  кому нужна помощь, в сентябре, а не в апреле.
- Ограничения MVP: нет чатов, нет ответов на комментарии, нет оценок и журнала.
  Комментарии односторонние: учитель → ученик.
- Статусы проекта: `idea → topic_draft → topic_submitted → topic_approved →
  product_draft → product_defined → in_progress → ready_for_defense → defended`.

## Дизайн-система

Сплав двух школ:

- [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/guidelines/overview/) —
  структура и поведение: **Clarity, Deference, Depth**, 8pt-ритм, мягкая
  глубина, сдержанный моушн, один интерактивный акцент.
- [Mailchimp Pattern Library](https://ux.mailchimp.com/patterns/color) —
  материал и характер: тёплая бумажная база, чернильный Peppercorn, Kale как
  акцент действий, Cavendish как редкий брендовый highlight и мягкие
  статусные оттенки.

Правило смешивания: Apple отвечает за иерархию, воздух и поведение; Mailchimp —
за цвет, теплоту и дружелюбие. Никаких неоновых градиентов, клякс и маскотов
в UI-хроме.

### Палитра

| Роль | Светлая тема | Тёмная тема |
| --- | --- | --- |
| Фон | Jasmine `#F6F6F4` | Peppercorn Deep `#1A1512` |
| Поверхность | Coconut `#FFFFFF` | Peppercorn `#241C15` |
| Основной текст | Peppercorn `#241C15` | Jasmine `#F6F6F4` |
| Вторичный текст | Peppercorn-65 `#716B67` | Portobello `#B7A9A1` |
| Границы и поля | Basmati `#DBD9D2` | Oyster `#403B3B` |
| Интерактивный акцент | Kale `#007C89` | Kale Light `#4FC8D6` |
| Брендовый highlight | Cavendish `#FFE01B` | Cavendish `#FFE01B` |
| Ошибка | `#A73205` + Yam `#FBCFBD` | `#FF7A66` + `#3A1B14` |
| Успех | `#00753A` + Cucumber `#D8EACC` | `#5BD48B` + `#17331F` |
| Предупреждение | `#8A5A00` + Squash `#FBEECA` | `#F2B75F` + `#35260C` |
| Информация | Kale + Cornflower `#C5DBF2` | Kale Light + `#1B2C3F` |

- Один интерактивный акцент — **Kale**. Cavendish жёлтый — только для
  брендовых highlight и особых CTA, всегда с текстом Peppercorn.
- Остальные цвета Mailchimp (Radish, Dragonfruit, Plum, Apricot, Apple,
  Pumpkin) допустимы в иллюстрациях, пустых состояниях и data-viz, но не в
  навигации, кнопках и статусных бейджах.
- Статусные пары «фон + текст» берутся из мягких оттенков Mailchimp и проходят
  WCAG AA.

### Структура

| Токен | Значение |
| --- | --- |
| Типографика | SF Pro / `-apple-system`, для веба Inter; body 15–17px, line-height 1.5, заголовки с tracking до `-0.035em` |
| Ширина текста | до 70ch |
| Сетка | 8pt, отступы щедрые |
| Радиусы | 10–20px, pill для бейджей |
| Тени | мягкие, низкая непрозрачность: `--shadow-soft`, `--shadow-card`, `--shadow-popover`, `--shadow-modal` |
| Материалы | `backdrop blur` только для навигации, шторок, модалок; при `prefers-reduced-transparency` заменяются на плотный фон |

### Статусы и цвет

Цвет статуса **всегда** дублируется текстом и иконкой — цвет сам по себе не
несёт смысла (важно для дальтоников и для доверия к дашборду «кто застрял»).
Шкала статусов — нейтральная прогрессия (Tuna → Kale → зелёный), отдельный
Yam/Pumpkin только для «застрял / нет активности».

### Моушн (исходная система Mailchimp)

- Микро-взаимодействия 140–200ms, панели и переходы 240–320ms.
- Easing как в iOS: spring / ease-out; hover-подъём карточек 1–2px.
- Stagger-появление списков 20–40ms, плавное заполнение прогресса, morph между
  шагами мастера темы.
- Не более 2 одновременных анимаций на экране. Никаких декоративных
  бесконечных циклов.
- Обязательно `prefers-reduced-motion` и `prefers-reduced-transparency`: без
  эффектов всё остаётся понятным.

### Доступность и производительность

- Контраст ≥ WCAG AA, кликабельная зона ≥ 44px, видимый focus-ring Kale.
- Приложение работает на слабых ноутбуках и Chromebook: без тяжёлых эффектов,
  больших видео и постоянных GPU-анимаций.

## Экраны

#### Публичная часть

1. Лендинг: заголовок «Начать индивидуальный проект вовремя», один акцентный CTA, 3–4 преимущества.
2. Вход / регистрация (ученик по инвайту класса).

**Ученик**
3. «Мой проект»: статусный степпер, карточка «следующий шаг», прогресс чек-листа,
   последний комментарий учителя, файлы.
4. Мастер темы: сфера интересов → исследовательский вопрос → формулировка темы,
   инлайн-подсказки и проверка «слишком широко / уже занято».
5. Выбор продукта: категория + примеры результата.
6. Работа над проектом: чек-лист по этапам, загрузка файлов, комментарии учителя.
7. Состояния: пустое, загрузка (skeleton), ошибка, успех.

**Учитель**
8. Дашборд «Кто застрял»: карточки/таблица — статус, причина застревания текстом,
   прогресс чек-листа, дни без активности, фильтр по классу и статусу.
9. Проверка темы: карточка заявки, approve / reject с комментарием,
   предупреждение «нельзя проверять свою тему».
10. Список классов и карточка ученика.

**Админ**
11. Классы, ученики, справочники, контрольные точки — сдержанно, плотная таблица.

## Промпт для open-design

```text
Ты — продуктовый дизайнер уровня Apple. Спроектируй интерактивный прототип веб-приложения «Индивидуальный проект» для школ (9–11 класс).

ЗАДАЧА
Помочь ученику вовремя начать и не застрять на теме, а учителю — увидеть, кому нужна помощь, в сентябре, а не в апреле. Интерфейс на русском языке.

ДИЗАЙН-СИСТЕМА
Сплав Apple Human Interface Guidelines (https://developer.apple.com/design/human-interface-guidelines/guidelines/overview/) и Mailchimp Pattern Library (https://ux.mailchimp.com/patterns/color).
Apple задаёт структуру: Clarity, Deference, Depth, контент главнее хрома, минимум рамок и линий, много воздуха, честная иерархия.

• Сетка 8pt, радиусы 10–20px, pill для бейджей, отступы щедрые.
• Цвет: светлая база Jasmine #F6F6F4, поверхность Coconut #FFFFFF, текст Peppercorn #241C15; тёмная база #1A1512, поверхность #241C15. Один интерактивный акцент — Kale #007C89 (в тёмной теме #4FC8D6). Cavendish #FFE01B — только брендовый highlight с текстом Peppercorn.

• Одновременно не более 2 анимаций на экране. Никаких декоративных бесконечных циклов.
• Учти prefers-reduced-motion и reduced transparency: всё остаётся понятным и без эффектов.
```

## Чек-лист реализации во frontend

- [ ] Общие токены (цвет, типографика, отступы, радиусы, тени, тайминги) — в CSS-переменных, не хардкодом в компонентах.
- [ ] Light и Dark темы, проверка контраста.
- [ ] Статус проекта = иконка + текст + цвет.
- [ ] Skeleton-загрузки вместо спиннеров на списках и карточках.
- [ ] `prefers-reduced-motion`: анимации отключаются, layout не прыгает.
- [ ] Фокус-стили и клавиатурная навигация на всех интерактивных элементах.
- [ ] Нет UI для чата, ответов на комментарии и оценок.

## Анти-паттерны

- Неон, кислотные градиенты, «кляксы», тяжёлые glass-панели на каждом блоке.
- Бесконечные фоновые анимации и параллакс.
- Цвет как единственный носитель статуса.
- Плотные формы без пустых состояний и подсказок «что дальше».
- Модалки для простых действий — предпочитать инлайн-панели и шторки.
