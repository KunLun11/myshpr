# ADR-08: Personal data and 152-FZ

**Status:** Accepted.

## Decision

- Store the minimum: full name, email, class, school. No birth date, SNILS, passport, address.
- Student data used only for the educational process; consent + privacy policy required.
- Hosting and backups inside Russia (localisation requirement).
- Retention: academic year + school-defined period; delete/anonymise per regulation.
- Role- and school-scoped access; log administrator actions.

See [ADR-09](adr-09-files.md).
