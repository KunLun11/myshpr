# Инструкция учителя

## 1. Вход и классы

1. Войдите по email и паролю, который выдал администратор школы.
2. На главной странице `/teacher` — ваши классы.
3. У каждого класса есть «Дашборд класса».

Учитель видит только свои классы. Чужой класс и проект недоступны.

## 2. Дашборд «Кто застрял»

Откройте класс → «Дашборд класса». Сверху — сводка: всего учеников, красные,
жёлтые, зелёные.

- **Красный** — нужно вмешаться: нет активности 14 дней, просрочена
  контрольная точка, просрочен обязательный пункт чек-листа, нет итогового
  файла перед защитой.
- **Жёлтый** — риск: нет активности 7 дней, близкий дедлайн, заявка ждёт
  проверки.
- **Зелёный** — всё идёт по плану.

Цвет всегда дублируется текстом и иконкой; рядом указана конкретная причина.
Фильтры: по цвету, по статусу проекта и поиск по имени. Карточка ученика
показывает прогресс чек-листа, дни без активности, ближайшую контрольную точку
и последний комментарий.

Открывайте дашборд минимум раз в неделю.

## 3. Проверка темы

Раздел «Проверка тем» показывает заявки ваших классов.

1. Откройте заявку: тема, вопрос, результат проверки на повтор и широту.
2. **Утвердить** — тема переходит в реестр, ученик получает статус «Тема
   утверждена».
3. **Отклонить** — обязателен комментарий с причиной; ученик увидит его в
   кабинете и сможет исправить тему.

Если проверка нашла замечания, для утверждения нужен комментарий. Тему с
блокирующим повтором утвердить нельзя.

«Реестр» (`/teacher/topics`) — утверждённые темы школы.

## 4. Карточка проекта

Раздел «Ученики» (`/teacher/projects`) → «Открыть проект».

Вкладки:

- **Обзор** — статус, тема, продукт, ближайшая контрольная точка.
- **Чек-лист** — «Подтвердить» выполненный пункт, «Пропустить» необязательный.
  Прогресс считается по обязательным пунктам.
- **Файлы** — что загрузил ученик. Скачивание доступно вам и администратору
  школы; публичных ссылок нет.
- **Комментарии** — напишите комментарий и выберите видимость:
  - «Ученику» — появится у ученика и создаст уведомление;
  - «Только учителям» — ученик его не увидит.

Комментарии односторонние: ученик не может ответить. Для срочной связи
используйте привычные каналы школы.

## 5. Уведомления и напоминания

- Колокольчик в шапке показывает уведомления: новая заявка, новый файл, продукт
  определён, комментарий.
- Напоминания создаются ежедневно: нет активности, приближается контрольная
  точка, просрочен чек-лист, не хватает итогового файла. Повторные напоминания
  не дублируются.

## 6. Типовые ситуации

| Ситуация | Что делать |
|---|---|
| Ученик не может зарегистрироваться | проверьте код класса и срок его действия; при необходимости создайте новый код в админке |
| Тема отклонена, ученик не видит причину | убедитесь, что при отклонении был комментарий |
| Ученик пропал из дашборда | проверьте фильтры цвета/статуса и поиск |
| Нужно исправить свою ошибку в комментарии | отредактируйте или удалите комментарий в течение рабочего дня |
| Ученик загрузил не тот файл | ученик удаляет файл сам; вы можете указать на ошибку комментарием |

По техническим сбоям передайте администратору время, действие и текст ошибки —
по `request_id` из ответа запрос находится в логах.
