# Чек-лист релиза

Отмечайте пункты при каждом релизе. Этап 7 считается завершённым, когда все
P0-пункты закрыты для пилотной школы.

## 1. Код и тесты

- [ ] `make lint` — ruff + eslint без ошибок.
- [ ] `make test` — backend-тесты зелёные на чистой БД.
- [ ] `alembic upgrade head` → `downgrade base` → `upgrade head` проходит.
- [ ] `alembic check` не находит расхождений моделей и БД.
- [ ] `npx tsc --noEmit && npm run build` в `frontend/`.
- [ ] `make test-e2e` — все пять сценариев зелёные, без флаков (2 прогона
      подряд).
- [ ] CI зелёный: backend, frontend, docker, security.

## 2. Безопасность

- [ ] `pip-audit` и `npm audit --audit-level=high` не находят уязвимостей.
- [ ] Rate limit проверен: 6-я регистрация/11-й вход → 429 с `Retry-After`.
- [ ] `RATE_LIMIT_BACKEND=redis` в prod; Redis с паролем, не опубликован.
- [ ] Cookies `httpOnly`, `SameSite=Lax`, `Secure` в prod.
- [ ] Origin/CSRF: запрос с чужим `Origin` на `POST` → 403.
- [ ] Проверено: ученик не читает чужой проект/файл, учитель — чужой класс.
- [ ] Комментарии `teachers_only` не видны ученику.
- [ ] Загрузка файлов: размер, расширение, MIME, сигнатура; бакет приватный.
- [ ] В логах нет паролей, токенов, тел запросов и ПДн.
- [ ] Секреты только в `deploy/.env` / secret manager, не в git.

## 3. Наблюдаемость

- [ ] `/api/v1/healthz` и `/api/v1/readyz` отвечают 200.
- [ ] В логах prod-формата есть `request_id`, `route`, `status`,
      `duration_ms`.
- [ ] `X-Request-ID` возвращается клиенту и находится в логах.
- [ ] `/api/v1/metrics` отдаёт метрики и закрыт от публичного доступа.
- [ ] Настроены алерты: `/readyz`, доля 5xx, ошибки фоновых задач, диск,
      сертификат.
- [ ] Ошибка фоновой задачи видна в `background_job_failures_total` и логах
      worker.

- [ ] Caddy выпустил сертификат; HTTP редиректит на HTTPS.
- [ ] `BASE_URL=https://... deploy/scripts/smoke.sh` проходит.
- [ ] Бэкап: `deploy/scripts/backup.sh` создал дамп и архив media, checksums
